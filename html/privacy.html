Privacy information

Privacy information Korean fork

Last updated: 2026-10-25

About this site

This independent Korean fork is maintained by i2na. It has no user accounts, advertising, analytics scripts, or contact form. Calculators and simulators run in your browser.

Browser storage

The site stores preferences such as language-independent unit and theme choices, quiz progress, and saved simulator work in your browser. You can remove these records using your browser’s site-data settings. The site does not send calculator inputs or saved work to the maintainer.

Hosting

This fork is configured for Vercel hosting. The hosting provider processes network requests, including IP addresses and request metadata, to deliver and protect the site. Fonts and application assets are served from this site. See Vercel’s privacy policy for its data practices.

Feedback and external links

Feedback is handled through public GitHub issues. Information you choose to submit is handled by GitHub and is visible to others. Do not post private information. External sites, including the original project, have their own privacy practices.

Questions and changes

For questions about this fork, use the contact page. This notice will be updated when the site’s data handling changes.
