Contact the Korean fork Feedback

This independent Korean edition is maintained by i2na. Please report translation errors and problems with this edition to this fork's GitHub repository.

Report an issue on GitHub

Include the page URL, the original and translated wording, and what should be corrected. For a calculator bug, include the inputs, unit system, expected result, and steps to reproduce it.

GitHub issues are public. Do not include passwords, private building information, personal contact details, or other sensitive data. A GitHub account is required to submit an issue.

The original project is by Controls Freak. This fork does not forward messages to the original author.
