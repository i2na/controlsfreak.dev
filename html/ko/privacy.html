개인정보 안내 한국어판

최종 업데이트: 2026-10-25

이 사이트에 관하여

이 독립 한국어판은 i2na가 운영합니다. 사용자 계정, 광고, 분석 스크립트와 문의 양식이 없습니다. 계산기와 시뮬레이터는 브라우저에서 실행됩니다.

브라우저 저장소

단위계와 테마 선택, 퀴즈 진행 상황, 저장한 시뮬레이터 작업 등은 브라우저에 보관됩니다. 브라우저의 사이트 데이터 설정에서 삭제할 수 있습니다. 사이트는 계산기 입력값이나 저장한 작업을 운영자에게 전송하지 않습니다.

호스팅

이 포크는 Vercel 호스팅용으로 구성되어 있습니다. 호스팅 제공자는 사이트 제공과 보호를 위해 IP 주소와 요청 메타데이터를 포함한 네트워크 요청을 처리합니다. 글꼴과 애플리케이션 자산은 이 사이트에서 제공합니다. 제공자의 데이터 처리 방식은 Vercel 개인정보 처리방침을 참고하세요.

의견 제보와 외부 링크

의견 제보는 공개 GitHub 이슈로 받습니다. 직접 제출한 정보는 GitHub에서 처리하며 다른 사람에게도 공개됩니다. 비공개 정보를 게시하지 마세요. 원본 프로젝트를 포함한 외부 사이트에는 각각의 개인정보 처리방침이 적용됩니다.

문의와 변경

이 포크에 관한 문의 방법은 문의 페이지를 확인하세요. 사이트의 데이터 처리 방식이 바뀌면 이 안내도 갱신합니다.
