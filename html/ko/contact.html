문의

한국어판 문의 의견 보내기

이 독립 한국어판은 i2na가 운영합니다. 번역 오류나 이 한국어판의 문제는 포크 저장소의 GitHub 이슈로 제보해 주세요.

GitHub에 문제 제보하기

페이지 주소, 원문과 번역 문구, 수정이 필요한 내용을 함께 적어 주세요. 계산기 문제라면 입력값, 단위계, 예상 결과와 재현 절차도 알려 주세요.

GitHub 이슈는 공개됩니다. 비밀번호, 비공개 건물 정보, 개인 연락처 등 민감한 정보를 적지 마세요. 이슈를 작성하려면 GitHub 계정이 필요합니다.

원본 프로젝트는 Controls Freak가 제작했습니다. 이 포크는 메시지를 원작자에게 전달하지 않습니다.
